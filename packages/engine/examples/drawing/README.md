# Visript 5.1 live samples

Open any `.viscript` in the editor, or set `sample_owner` in [import.sql](import.sql) and run it to import all six as private visualisations. Re-importing preserves edits.

01: local calendar rings and frame pulse; 02: transforms/additive blending; 03: audio waveform and Bézier; 04: image/gradient (requires access to the supplied sprite asset); 05: world lines/planar shape/overlay; 06: GPU noise grid and deterministic particles.

Use live playback and Capture thumb at different aspect ratios. Inspect the properties on 01 to see delta-driven phase. No database migration is required.
